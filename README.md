# 創業貸款資格核對小工具

一個單檔、免安裝的網頁工具，讓有意申請創業貸款的人在正式送件前，先依「微型創業鳳凰貸款要點」與「就業保險失業者創業協助辦法」（兩者皆自115年8月1日生效）逐條核對自己是否符合資格，並比較兩方案分別適不適合自己。用瀏覽器打開 `index.html` 即可使用，不需要架伺服器、不需要安裝任何軟體、不會把任何資料送到伺服器。

> ⚠️ **使用警語**
> 本工具僅供教學、課程及個人使用，**禁止未經授權公開發布、販售或商業化使用**。
> 本工具僅做「資格自我核對」，並非官方審查系統；正式核准與核貸金額，仍由勞動部勞動力發展署、信保基金、承貸金融機構代表及專家學者組成之審查會綜合評估決定。

**本工具不做申請書填表**——若已確定要申請「微型創業鳳凰貸款」並要填寫正式申請書，請改用同一分類目錄下的 `phoenix-loan-generator` 工具。

---

## 功能總覽

### 1. 問答式健檢
依序回答「事業登記狀況」「負責人身分與經營狀況」「個人資格條件」「信用與貸款紀錄」四大區塊的問題，畫面下方「核對結果」會即時更新，不需要按送出按鈕。

### 2. 逐條 checklist
兩個方案（微型創業鳳凰貸款／就業保險失業者創業貸款）各自列出所有適用的資格條件，每條標示 ✅ 符合／❌ 不符合（附原因與法規出處）／⚠️ 尚未填答。

### 3. 結論卡片與貸款額度
依填答結果自動判斷：兩者都不符合時列出關鍵原因；僅一方符合時建議申請該方案並顯示最高貸款額度（依事業登記型態試算 50 萬或 200 萬）；兩者皆符合時說明「同一事業只能擇一申請」的互斥規定，並列出兩方案的差異重點供自行判斷。

### 4. 增貸備註（選填）
若您是同一事業要辦理「增貸」，勾選頁面底部的核取方塊，會顯示增貸次數上限與累計核給金額規定的提醒文字。

---

## 使用方式

1. 直接用瀏覽器（建議 Chrome / Edge）開啟 `index.html`
2. 由上而下依序填答每個問題
3. 畫面下方「核對結果」即時顯示兩方案的逐條核對與結論
4. 依結論決定要申請哪個方案，再前往勞動部勞動力發展署所屬分署或洽詢顧問辦理正式申請
5. 若要重新核對，可按右上角「重新填寫」清空所有內容

---

## 重要提醒

- 本工具的判斷邏輯是依兩份法規條文逐條整理而成，僅供自我核對參考，**不具法律效力**
- 法規條文如有再次修正，本工具的判斷邏輯需要對照更新，請以勞動部勞動力發展署最新公告為準
- 兩份法規皆提及第三個互斥方案「失業中高齡者及高齡者創業貸款」，本工具僅將其納入「已獲貸且未清償則排除資格」的判斷，未取得該法規全文，故不單獨提供其資格核對
- 填答內容僅存在您瀏覽器的記憶體中，重新整理頁面即會清空，不會被儲存或送出
